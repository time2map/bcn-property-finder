# TODO-035 — UI polish, branding, app name

## Idea

Before public launch: name the app, define a visual identity, and clean up the interface so it reads as a finished product rather than a dev tool.

## App name

Must be decided alongside TODO-033 (multi-city). Requirements: not BCN-specific, ideally works in EN/ES, memorable. Candidates TBD.

## UI items

- Typography: choose a clean readable font pair (headings / body). Currently default Mantine.
- Colour palette: the red/orange score ramp is good; surrounding UI chrome (sidebar, cards) should feel calm and neutral to let the map be the hero.
- App icon / favicon.
- Panel header / logo placement.
- Mobile layout review.
- Empty state: what does a first-time user see before they interact? Should communicate the value immediately.
- Remove or hide any remaining developer-facing elements.

## Notes

- Do not over-design — the map is the product. UI should be minimal and get out of the way.
- Reference: felt.com, Datawrapper, Mapbox Studio — clean, professional, map-first.
