# TODO-031 — Weight presets / questionnaire

## Idea

Replace (or supplement) the raw weight sliders with a short questionnaire: "What matters most to you?" → 3–4 simple questions → weights set automatically.

Example questions:
- "Do you have a car?" → affects driving weight
- "How important is peace and quiet?" → noise weight
- "Do you walk or cycle to errands?" → walkability weight

Offer 2–3 named presets as an alternative: "Remote worker", "Family", "Nightlife lover".

## Why

Sliders (0–10 weights) are opaque to casual users. Presets + a short quiz lower the barrier to a meaningful first result.

## Notes

- Sliders remain accessible as "Advanced" mode for power users.
- Presets could be shared via URL param for editorial use (e.g. link to "best barri for remote workers" preset).
