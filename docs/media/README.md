pitches, posts and press notes are written later, one file per piece, in `docs/media/pieces/`.

Written 2026-11-14, rewritten 2026-11-15 for the agreed idea. Builds on the "Launch strategy" section of [ROADMAP.md](../ROADMAP.md), which already decided:
keep the current functionality, work on reach, no gated feature is switched on for the launch.

## Rules for everything in this folder

- **No press link before A1 (hosting) and A2 (observability) are live.** See [TODO-054](../features/TODO-054-cdn-hosting-burst-traffic.md).
- **Every number in a pitch is computed from the shipped data and checked by hand** on a few buildings. No number
  in this folder is a result yet: the "number to compute" fields are tasks.
- **Check [DATA_LICENSES.md](../DATA_LICENSES.md) before a story goes out.** Street flooding (RESCCUE) has no
  licence and is not used in any press story. Never write "official" or imply that the Ajuntament, the Generalitat
  or Catastro support the product.
- **Public links use the final domain** (`https://livability.time2map.com`), never a fork or a preview address.
- Barri-level statements are always "share of homes in the barri that meet X", never a single barri score
  (see [DEPRECATED-027](../features/DEPRECATED-027-territory-cards-seo-urls.md)).
