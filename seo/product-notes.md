1. Мультиязычность

Для SEO-страниц (Astro) — ES + EN с первого дня, это важно, они разные аудитории с разными запросами. Испанские запросы: "mejores barrios barcelona", "mapa calidad de vida barcelona". Английские:
"best neighborhoods barcelona expats".

Для SPA (интерактивный инструмент) — EN сначала, ES потом. Полная i18n в React это работа, и для v1 незначимая. Для глобальной аудитории EN достаточно. Испанская локализация SPA — это v2 после первых
сигналов.

2. Community launches (HN, TG, etc.)

Ты прав насчёт маркетинговых кнопок. HN "Show HN" жёстко реагирует на коммерциализацию в инструменте — там ценят "я сделал это, потому что мне было нужно, вот исходники".

Стратегия по каналам разная:

┌──────────────┬───────────────────────────────┬────────────────────────────────────────┐
│    Канал     │             Tone              │               Что убрать               │
├──────────────┼───────────────────────────────┼────────────────────────────────────────┤
│ HN Show HN   │ "I built this for myself"     │ любые CTAs кроме GitHub                │
├──────────────┼───────────────────────────────┼────────────────────────────────────────┤
│ TG чаты (ru) │ полезный инструмент для Барсы │ можно оставить email subscribe         │
├──────────────┼───────────────────────────────┼────────────────────────────────────────┤
│ LinkedIn     │ демо экспертизы time2map      │ B2B CTA уместен                        │
├──────────────┼───────────────────────────────┼────────────────────────────────────────┤
│ Product Hunt │ discovery tool                │ email subscribe + time2map attribution │
└──────────────┴───────────────────────────────┴────────────────────────────────────────┘

Вывод: email subscribe — единственный CTA который не режет ни одну аудиторию. Остальное — зависит от канала. Можно сделать его ненавязчивым.

4. V1 stripped down — хорошая идея

Убрать добавление квартир — правильно по нескольким причинам:
- Изохрона + пины требуют OTP2 backend, это инфраструктурная зависимость при публичном трафике
- Гексагональный индекс самодостаточен и визуально сильный
- Проще объяснить: "карта качества жизни по районам Барселоны"
- Меньше онбординга нужно

Что остаётся в v1:
- Hex livability layer с composite score
- Переключение весов (noise / walkability / etc.)
- Границы и названия barri
- Легенда с объяснением что значат цифры
- Email subscribe

Email список — однозначно делаем. Даже 300–500 подписчиков это:
- Аудитория для анонса каждой новой фичи
- Сигнал интереса по географии (кто подписывается)
- В будущем: рассылка "лучшие кварталы Барселоны этого месяца" = трафик обратно на сайт
- Потенциально монетизируется через спонсорство рассылки когда будет >2K

По расширению на всю Испанию

Архитектурно это несложно если данные есть — OpenData по шуму и пешеходности есть по большинству крупных городов. OTP2 работает с любым GTFS. Реалистично после Барселоны: Мадрид, Валенсия, Малага
(популярна у expats). Это хороший SEO moat — "mapa calidad de vida España".

  ---
Итого: что делаем для v1 public

1. Убираем всё связанное с пинами/изохронами из публичного UI (или скрываем за feature flag)
2. Полируем hex layer — он должен быть красивым, это лицо
3. Добавляем email subscribe (простая форма, Mailchimp или Resend)
4. OG-теги для шаринга в соцсетях
5. Subtle "Built by time2map" в футере — без CTA, просто attribution
6. EN текст в UI
